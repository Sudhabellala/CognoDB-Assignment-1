# Graph Database Cloud Benchmark: CognoDB vs. Neo4j, Memgraph, ArangoDB, Dgraph (Java)

A reproducible, honest benchmark comparing [CognoDB Cloud](https://cognodb.com) against four
other graph database platforms on identical hardware, data, and query workloads. Java/Maven port
of the original harness.

## 1. Why these five platforms

- **CognoDB Cloud** — required by the assignment.
- **Neo4j Community** — same wire protocol/query language family as CognoDB (Bolt + Cypher).
- **Memgraph** — also Bolt + Cypher, different (in-memory) storage architecture.
- **ArangoDB** — multi-model, AQL query language.
- **Dgraph** — native DQL, distributed-by-design engine.

All four comparison platforms are self-hosted via Docker, resource-capped to match CognoDB's
free tier (0.5 vCPU / 256 MB RAM / 1 GB disk — see `docker-compose.yml`).

## 2. Dataset

[SNAP `email-Enron`](https://snap.stanford.edu/data/email-Enron.html): 36,692 nodes, 367,662
directed edges. Each node also gets a synthetic `group = id % 100` property for the
filtered/indexed lookup workload.

```bash
mvn compile exec:java -Dexec.mainClass=com.wexa.benchmark.Main -Dexec.args="download-dataset"
# or, after building the jar:
java -jar target/graph-benchmark.jar download-dataset
```

## 4. How to reproduce

```bash
# 1. Build (requires JDK 17+ and Maven)
mvn clean package

# 2. Start the four self-hosted platforms, resource-capped
docker compose up -d

# 3. Set CognoDB credentials (never commit these)
cp .env.example .env
# edit .env: COGNODB_URI=bolt+s://<instance-id>.databases.cognodb.cloud
#            COGNODB_PASSWORD=<your password>

# 4. Download and preprocess the dataset
java -jar target/graph-benchmark.jar download-dataset

# 5. Run the full suite against every platform (loads data + runs all workloads)
java -jar target/graph-benchmark.jar run-all cognodb neo4j memgraph arangodb dgraph

# 6. Generate the results tables
java -jar target/graph-benchmark.jar report > RESULTS.md
```

Individual platforms/steps can be run separately:
```bash
java -jar target/graph-benchmark.jar load neo4j
java -jar target/graph-benchmark.jar bench-reads neo4j
java -jar target/graph-benchmark.jar bench-mixed neo4j
java -jar target/graph-benchmark.jar run-all neo4j --skip-load
```
